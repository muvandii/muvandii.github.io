# Retail Sales Consolidation

> **Template note:** this repository is the standard starting point for every project in the
> Muvandii portfolio. Keep this structure (folders and file names) exactly as-is — the
> portfolio website reads `documentation/project.md`, `documentation/modules.md` and
> `images/cover.png` automatically. Replace the sample content with your own project's content.

Automated consolidation of monthly sales reports from 12 regional spreadsheets into one refreshable Power BI dashboard — cutting report preparation time by 72%.

![Project cover](images/cover.png)

## Repository Structure

```text
project-repository/
│
├── documentation/          ← read by the portfolio website
│   ├── project.md          ← project overview (metadata + case study)
│   └── modules.md          ← module-by-module documentation
│
├── images/                 ← all images referenced from the documentation
│   ├── cover.png           ← main project image (card + case-study hero)
│   ├── screenshot-01.png
│   └── screenshot-02.png
│
├── src/                    ← source files (workbooks, .pbix, scripts, code)
│
├── data/                   ← sample/input data (add if relevant)
│
└── README.md               ← this file
```

## Quick Start

1. Copy this repository as the starting point for a new project.
2. Replace the content of `documentation/project.md` and `documentation/modules.md` with your project's details.
3. Put your main project image at `images/cover.png` and any screenshots in `images/`.
4. Put your actual source files in `src/`.
5. Push the repository to GitHub (it must be **public** for the portfolio to read it).

That's it — the portfolio picks the project up automatically. See the portfolio README for the full guide.
